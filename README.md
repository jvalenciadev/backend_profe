# AULA PROFE - Backend

Motor de servicios basado en NestJS.

## Tecnologías
- **Framework**: NestJS
- **ORM**: Prisma
- **Database**: PostgreSQL
- **Cache**: Redis
- **Security**: JWT + CASL (RBAC/ABAC)

## Comandos Útiles
- `npm run start:dev`: Modo desarrollo.
- `npx prisma studio`: Explorador de base de datos.
- `npm run build`: Compilación de producción.
